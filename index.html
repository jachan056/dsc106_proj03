About the data

🌐

What is CMIP6?

The Coupled Model Intercomparison Project Phase 6 is a coordinated international effort to simulate past and future climates using numerous models. This project utilizes CESM2 from NCAR.

🏭

What is SSP5-8.5?

SSP5-8.5 is a high-emissions scenario where radiative forcing is projected to reach 8.5 W/m² by 2100 — representative of a world heavily reliant on fossil fuels with little climate policy.

🌡️

Temperature Changes

Each value shows how much warmer or cooler a location is relative to its average during 1850–1900 (pre-industrial). Positive values indicate warming above baseline.

⚙️

Data Pipeline

Raw zarr data was loaded via Google Cloud, converted from Kelvin to Celsius, averaged annually, and sampled every 5 years. Regions were assigned by latitude threshold.
