About the data

🌐

What is CMIP6?

CMIP6 is an international climate modeling project used to simulate past and future climate conditions.

🏭

What is SSP5-8.5?

SSP5-8.5 is a high-emissions scenario that represents a future with continued fossil fuel reliance.

🌡️

Temperature Changes

Each value shows temperature change relative to the baseline period. Positive values show warming, while negative values show cooling.

Design rationale

Visualization Design Decisions

The visualization was designed to help users explore how global temperature change varies across both space and time. A world map was chosen as the primary visual encoding because climate change is inherently geographic, and the spatial layout allows users to quickly compare warming patterns across regions. Temperature anomalies were encoded using a blue–white–red color scale, where blue represents cooling and red represents warming, because this diverging color scheme intuitively communicates temperature differences and emphasizes extreme warming.

Interactive components were added to support deeper exploration of the dataset. A year slider allows users to observe how warming changes over time, while the play button animates temporal progression to highlight long-term trends. A temperature filter slider was included so users can focus on locations within a selected warming range. Clicking on map locations generates side-by-side time series charts that enable comparison between two regions over time. These interaction techniques were chosen to support both overview and detailed analysis within a single interface.

Several alternative designs were considered during development. A choropleth map was initially explored, but it reduced spatial precision because the dataset represents gridded climate points rather than country-level values. Different layouts for the comparison charts were tested, including placing both charts horizontally, but the final stacked vertical layout improved readability and reduced visual crowding.

Development process

The application was developed through an iterative process involving data preprocessing, interface design, interaction development, and refinement of the visualization layout.

To ensure the project remained organized, we divided the workload by data processing tasks and specific interaction tools. Overall, the project took approximately 60 person-hours to complete. The most time-consuming aspects involved identifying the most effective design for the main map to ensure information was conveyed successfully, as well as ensuring that all interactions worked together without breaking.
